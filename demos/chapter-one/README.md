# 第一章《排队的面包店》

可从开场走到唯一结尾的独立网页试玩。玩家是银行新人调查助理，走访留灯烘焙老店、设备供应商与待开业新铺子，核对资料、摆放收支，向上级交出报告。

本轮由用户明确分配独立 demo 的程序、美术、交互及验证；范围仅为 `demos/chapter-one/`。在已有章节流程上，把场景与查看交互改为 Three.js 实时三维，补充对应浏览器验证；不改原 `prototype/` 的接口、模型或测试。

## 启动

在仓库根目录运行（只需 Python 3，试玩不需要安装 Node 依赖）：

```bash
python3 -m http.server 4186 --bind 127.0.0.1 --directory demos/chapter-one
```

打开 <http://127.0.0.1:4186>。不要直接双击 HTML，浏览器需要通过 HTTP 加载模块。也可在本目录运行 `npm start`。

三维引擎和游戏代码都在本目录，运行时不请求图片或外部 CDN，不连接生成服务，不发送玩家资料。进度只保存到当前浏览器的 localStorage；禁用保存时仍能完成当前试玩。刷新可续玩；设置中可清除本章进度并重玩。

## 怎么玩

1. 推门进入，认识陈叔与小禾。阅读由点击或空格推进，不计时，可略过对话。
2. 鼠标移到模型上才显示轮廓，点击拿近查看，或通过“场景物件”取得资料。老店核对后，供应商与新铺子先后任选。
3. 打开档案箱查看、标记、并排比较。已选比较资料关闭或刷新后仍保留，可撤出换页。
4. 点选资料摘记，再点对应位置，区分现金、预测、旧款与新支出。放错可改，不扣机会。
5. 回老店摆出两笔付款与未来 30 天收支，出示预算和排期追问，再向上级核对报告。
6. 报告通过后进入同一段尾声；可回看报告、资金推演，或重新开始。

物件在中央检查窗口放大展示，旁边显示人物说法、观察与资料；拖动或单指滑动旋转，滚轮或双指缩放，也可用左右旋转按钮、方向键和 Home 复位。Tab / Enter 可以完成全部操作，Esc 放回物件。设置可减少动画、开启轻声环境音，也响应系统减少动画偏好。手机点击模型直接进入检查，不需要先悬停；窄屏检查窗口上下排列并可滚动阅读。

## 故事与金额边界

依据根目录《这笔钱借给谁_第一章故事重设计草案.md》。三处调查均须完成，八份核心资料均须取得；生活物件不参与通关门槛。申请和还款条件示例分别成页，资料标明来源、记录、说法、计划或预测。

金额内部用整数千元，画面显示万元；所有事实固定，不以生成式 AI 决定数值或计算。

| 节点 | 演算（万元） | 含义 |
| --- | --- | --- |
| 两笔付款后 | 2 + 20 − 10 − 12 = 0 | 假设申请贷款在明天付款前到账，尚未批准 |
| 老店预计经营现金净流入 | 18 − 16 = 2 | 未来 30 天预测，不是当前现金，也不是净利润 |
| 原方案本期预计余额 | 0 + 18 − 16 − 6 + 0 − 1.8 = −5.8 | 预计资金缺口 5.8；不代表可以透支 |
| 眼前尾款差额 | 10 − 2 = 8 | 没有新资金或已确认展期时，仍待落实 |

暂停尚未签约的新店不启动 12 万元和另需 6 万元新增支出，但不解除尾款。结尾在调查当晚收束，不暗示融资获批、供应商已延期或债务已经解决。月末预测不能保证逐日或整个贷款期限安全。

## 美术与演出

用户确定偏写实方向：三处场景使用近距离室内镜位，分别呈现旧木与绿漆的老店、金属设备维修间、尚未装修的新铺子。全部用 Three.js 几何构建：墙体、地板、窗框、灯具、工作台、人物和 18 件可查看物件；使用程序木纹和微表面、冷色窗光、暖色吊灯、投影、环境遮蔽与克制的高光泛光。柜台玻璃、纸页弧度、账本缝线、金属铰链和螺丝均为实际几何；人物改为成人比例。文字用本地 Canvas 绘制到模型，金额与事实仍由原有数据提供。没有使用图片背景、图片平面模型或外部模型素材。旧 `assets/*.webp` 留作历史素材，不再加载。当前仍是程序建模的偏写实原型，不是扫描资产或影视级角色；低端设备帧率与实际手机 Safari 尚需实机验证。

`scene3d.js` 负责三维场景、射线拾取、OutlinePass 悬停轮廓、中央模型和 OrbitControls 旋转缩放。场景按需绘制，静止时不持续刷新；各空间缓存复用，检查窗口复用同一个 WebGL 上下文。`props3d.js` 是可复用的程序模型。`cinema.js` 只处理对白文字淡入。WebGL 不可用时明确提示，仍可通过“场景物件”阅读、取证和通关。

Three.js 0.186.1 及所需附加模块打包在 `vendor/three.js`，保留其 MIT 许可，仅适用于该第三方库，不为项目新增许可证。来源与制作方式见 [ASSETS.md](ASSETS.md)。修改引擎版本后重新构建：

```bash
cd demos/chapter-one
npm ci
npm run vendor
```

打包工具 esbuild 仅在开发时使用，玩家仍可直接通过 Python 静态服务器启动。背景声仍由 Web Audio 合成，默认关闭。

## 文件与检查

- `data.js`：角色对白、三处热点、八份资料与报告问题。
- `model.js`：固定金额、调查及报告提交条件。
- `app.js`：操作、核对、存档和唯一结局。
- `styles.css` / `cinema.css` / `scene3d.css`：布局与响应式。
- `scene3d.js` / `props3d.js`：三维场景、模型、描边与检查交互。
- `cinema.js`：对白文字演出。
- `scripts/vendor.mjs` / `vendor/`：可复现的本地 Three.js 引擎打包及许可。
- `tests/model.test.mjs` / `tests/browser.cjs`：模型与真实浏览器操作回归。

从仓库根目录运行：

```bash
npm test --prefix prototype
npm test --prefix demos/chapter-one

# 浏览器检查复用项目原有的 Playwright 和 axe 开发依赖。
npm ci --prefix prototype
cd prototype
npx playwright install chromium
cd ..

# 另一个终端保持 4186 服务运行，然后执行：
npm run test:browser --prefix demos/chapter-one
npm run test:3d --prefix demos/chapter-one
```

可设 `CHAPTER_ONE_URL` 更换服务地址，`CHROME_PATH` 指定已安装的 Chromium。`CHAPTER_ONE_SCENARIO` 可只跑名称匹配的场景，默认全部运行。截图和 JSON 结果在 `test-results/`，不提交。实际验证记录见 [TESTING.md](TESTING.md)。

只验证过 Chromium 桌面与移动视口模拟；实际手机 Safari 和触屏设备体验仍需团队试玩。没有配音或真人视频，尚未用真实玩家验证时长与趣味。不要为本候选原型擅自增加开源许可证。
