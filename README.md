# 账面之下

**第一章 · 排队的面包店**

Finance Playground · 玩转金融

一款用剧情调查理解企业经营与现金流的网页游戏。你是一名刚入职银行的员工，跟随林姐调查留灯烘焙的扩店申请：老店门外排着队，生意热闹，钱就一定够用吗？

**[在线试玩](https://zhangmianzhixia.com) · [运行说明](运行说明.md) · [部署与后续更新](DEPLOYMENT.md)**

![《账面之下》的面包店与窗边账本](public/scenes/home-960.webp)

## 怎么玩

点击现场实物，读原件、问情况，再用证据核对你的判断。算术由系统完成，玩家要理解的是钱什么时候收、什么时候付，以及哪些说法已经被证实。

| 调查地点 | 玩家要做的事 |
| --- | --- |
| 老店 | 核对账本、待付款和首款回执；三项主线完成即可前进，支线不拦路。 |
| 新铺 | 对照租金、装修、设备和筹备资料，核对八项计划日期。 |
| 资金桌 | 分清可用资金与待付款，点选日期、两条独立原始依据和发货先后。 |
| 林姐办公室 | 明确点击“交给林姐”，接收后查看公司透视图；未查清的资料可返回补查并再次交接。 |

资料包可同时查看全部 27 个资料格，已收集原件能反复阅读。四条可选支线补充历史出资、街坊关系、顾客与开业计划；未调查的内容不会被当作确定结论。

当前版本包含独立首页、五段剧情视频、六首场景配乐、铅笔手记界面、电脑与手机适配，以及浏览器本地进度保存。视频可暂停、静音和跳过，任务与道具说明随时可回看。

## 立即运行

**只想玩：** 打开[在线版本](https://zhangmianzhixia.com)。也可在 GitHub 点击 **Code → Download ZIP**，完整解压后双击 `开始游戏.html`；请保留同目录的 `public/` 文件夹。离线游玩不需要 Node.js、服务器或账号。

**想看源码并修改：** 使用 Node.js 22.12+ 或 24，安装 npm 后运行：

```bash
git clone https://github.com/Starxxgazer/finance-playground.git
cd finance-playground
npm ci
npm run dev
```

打开终端显示的地址。构建和预览：

```bash
npm run build
npm run preview
```

构建生成静态站点 `dist/`，并重新生成离线入口 `开始游戏.html`。完整步骤、操作方式和常见问题见[运行说明](运行说明.md)。

## 源码结构

```text
src/
  App.jsx              游戏界面与交互组合
  components/          场景、原件、资金桌、资料包、视频与配乐
  game/                故事资料、状态机、资金核对与补查逻辑
  design/              仅开发环境使用的 UI 试览
public/
  scenes/ characters/  场景和人物
  items/ ui/           资料图标与界面材质
  videos/ audio/       本地视频、音乐与署名
  fonts/               字体及许可说明
scripts/
  package-game.mjs      打包可直接打开的离线入口
  deploy-game.py        按版本部署、校验与回滚
开始游戏.html            无需安装依赖的离线试玩入口
```

界面使用 React，构建使用 Vite。游戏在浏览器内运行，无业务后端；调查进度保存在当前浏览器的本地存储，不上传到服务器。金融计算和推进条件由固定模型与状态机控制，运行时不调用 AI 服务，不随机决定事实或计算结果。
